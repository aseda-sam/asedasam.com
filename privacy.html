Privacy Policy

Hub, asedasam.com. Last updated 21 Nov 2026.

Who uses Hub

Only its owner. Hub is a personal app, and it isn't offered to anyone else.

What it reads

With its owner's permission, Hub reads data in the owner's own Google accounts. It never reads anyone else's account.

Where the data goes

The data stays on the owner's own computer. Some of it is sent to an AI service, Anthropic's Claude, so it can be summarised and sorted for the owner. It is never sold, never used for advertising, and never shared with anyone else.

Hub's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be withdrawn at any time from the Google account's permissions page, which stops Hub reading anything further.
